# 📝 Almadrasa Notes

A fully responsive notes web application built with **Vanilla JavaScript**, designed as a diploma project for [Almadrasa.com](https://almadrasa.com) — taught by **Eng. Mohamed Abu Sarea**.

🔗 **[Live Demo](https://yomnaelsafty.github.io/Almadrasa_Notes/)**

---

## ✨ Features

- 📌 **Pin Notes** — Mark important notes as pinned, displayed separately at the top
- ➕ **Add Notes** — Create notes with title, author, and body
- ✏️ **Edit Notes** — Inline editing directly on the note view
- 🗑️ **Delete Notes** — Remove notes with a confirmation prompt
- 🔍 **Search** — Filter notes by title in real time
- 💾 **LocalStorage** — All notes persist across sessions
- 📱 **Responsive Design** — Fully adapted for mobile with a dedicated mobile UI

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/yomnaelsafty/Almadrasa_Notes.git

# Navigate to the project
cd Almadrasa_Notes

# Install dependencies
npm install

# Start dev server
npm run dev
```

## 💡 Key Concepts Used

- **SPA Pattern** — Single HTML page with dynamic content rendering
- **ES Modules** — Code split across multiple JS files using `import/export`
- **LocalStorage** — JSON serialization for persistent data
- **DOM Manipulation** — Dynamic HTML generation via `innerHTML`
- **Event Delegation** — Efficient event handling on dynamically rendered elements
- **Responsive Design** — Mobile-first approach with CSS media queries
